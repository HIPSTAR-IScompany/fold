# Infoton glossary

| Term | Reading in this edition |
|---|---|
| Infoton | A semantic unit that can be referenced from another context; the source also retains its research vocabulary for unresolved meaning |
| FAM | A language describing semantic units and structures of observation, procedure, output, and verification |
| FAMJSON | A representation carrying a semantic unit, distinct from an arbitrary JSON file |
| refFAM | Reusable ways of asking, seeing, defining conditions, and testing |
| Infoton Cluster | A local structure retaining related candidates, observations, interpretations, and unresolved state |
| DeFold | Resolve and project an independent reference |
| unFold | A merge or replacement that can break a semantic boundary |
| OAE | An observation or evaluation with observer, rule, subject, time, and scope |
| Provenance | The author, source, revision, and transformations behind a result |
| Unknown | Unresolved; not automatically false, absent, or ⊥ |
| ⊥ | A connection or stopping result defined by the selected contract, with its reason retained |

Return to the Japanese sources for precise definitions. Comparisons to general mathematics and computing terminology need explicit purposes and applicability conditions.
