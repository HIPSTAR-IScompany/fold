# Fold — 情報子を観測し、つなぎ、試す

同じ情報でも、誰が、どの文脈と目的で扱うかによって、意味も働きも変わる。Foldは、その違いを消さずに記述し、持ち運び、検証するための情報子工学の公開入口です。

情報子、FAM、動的な関係構造、意味・効果のEvidence、Fold protocolを横断して扱います。研究の原典はManifest、実装は各componentに保ち、ここでは分野を跨いで読める解説を編みます。

## 読み始める

- [情報子工学の入口](../research/index.md): 何を情報として拾い、何を変換で失うか。
- [情報子クラスターと動的グラフ](../research/infoton-cluster.md): 未確定の候補と関係を更新する。

- [FAMと実装への接続](../engineering/index.md)、[protocolの地図](../protocols/index.md)。
- [用語集](../glossary/index.md)、[原典・実装索引](../reference/index.md)。

## 学際的な研究の入口

科学、工学、宗教、神学、哲学、芸術は、それぞれの問いと証拠を保って接続できます。言霊、祈り、美、作者性を、測定しやすい指標へ置換して捨てない。実装の観測結果も、意味の好みで書き換えない。
