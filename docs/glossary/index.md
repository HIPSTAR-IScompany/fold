# 情報子の用語集

| 語 | この版での読み方 |
|---|---|
| 情報子／Infoton | 別Contextから再参照できる意味単位。未確定の意味状態を扱う研究語彙も原典に保持 |
| FAM | 意味単位と観測・手続き・出力・検証の構造を記述する言語 |
| FAMJSON | 意味単位を運ぶ表現。単なるJSONファイルと区別 |
| refFAM | 問い方・見方・成立条件・検証方法を再利用するための記述 |
| 情報子クラスター | 関係する候補・観測・解釈と未解決を保持する局所構造 |
| DeFold | 独立した参照先を解決・表示する操作 |
| unFold | 意味境界を壊し得る結合・置換操作 |
| OAE | 観測者・規則・対象・時点・射程を伴う観測／評価の記録 |
| provenance | 誰の、どのsource・revision・変換に由来するか |
| unknown | 未確定。false・不存在・⊥へ自動変換しない |
| ⊥ | 対象の契約で定める接続不能・停止結果。理由を保持 |

用語の細部は下記の日本語原典へ戻ります。一般的な数学・情報学の用語との対応は、目的と適用条件を指定して比較します。
