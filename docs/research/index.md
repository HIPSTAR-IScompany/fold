# 情報子工学の入口

情報子工学は、情報が観測者・文脈・目的・変換経路によって異なる意味や働きを持つ条件を、記述・接続・比較する研究領域です。Spiritual Engineeringが設計哲学を、Infoton Engineeringが研究・工学領域を、Context Engineeringが実装技法の一つを担います。

## 表現する前の選択

何を観測対象にし、何を同一視し、何を捨て、どの表現へ写像したのか。この選択も研究対象です。「量子化以前」はADC以前だけを指す語ではなく、記号化・表現化へ入る前の分類や意味選択も含みます。

FAMを使う基本説明では、入力対象をψ、意味の経路を∇φ、目的・出力側をλ、観測・検証をQとして扱います。これは読解上の対応であり、各実装の関数signatureは実装正本で確認します。同じ対象でも組合せが変われば、戻り値や接続可否が変わります。

## 原典の小さな例

糞は、衛生の系では忌避対象、蛆虫には餌、子供の発話遊びでは笑い、適切な変換装置を通せば燃料になります。テキストの悪口を蛆虫へ渡しても、文字を解釈するportがなければ餌にはなりません。

対象の「価値」を一つへ固定せず、どの系・目的・変換で成立するかを記録する。接続不能は⊥として返せます。⊥を出せる設計だけで個別仮説が実証済みになるわけではなく、何が観測されれば説明を棄却・修正するかも明示します。

## どう実験するか

同じモデルと入力を使い、context選択や表現だけを変える。作者が採用した出力、失われた文化的意味、誤配送、停止、修正回数を記録する。速度だけでなく「目的を保った成果物が得られたか」を比較します。評価者が何を見たか、どの規則で判断したかも保存します。

旧称・信仰・形而上学の系譜は原典に残します。既存分野への対応は同一性の証明ではありません。研究対象の未拘束条件は[EvidenceとOAE](evidence-and-oae.md)へ接続します。
